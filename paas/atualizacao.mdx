Atualizar é baixar a imagem nova e reiniciar. As migrações de banco são
aplicadas sozinhas, na subida.

<Steps>
  <Step title="Leia as notas da versão">
    Elas dizem se há passo manual ou mudança de configuração. Na maior parte das
    versões, não há.
  </Step>
  <Step title="Faça backup">
    Sempre. Ver [backup e restauração](/paas/backup-e-restauracao).
  </Step>
  <Step title="Baixe e reinicie">
    ```bash
    docker compose pull
    docker compose up -d
    ```
  </Step>
  <Step title="Confira">
    ```bash
    docker compose run --rm app doctor
    ```
  </Step>
</Steps>

## Atualize em degraus

Suportamos atualização a partir das **duas versões anteriores**. Se a sua
instalação está mais atrasada, atualize em etapas, na ordem das versões — não
pule direto para a mais recente.

<Warning>
  Pular versões não é suportado. As migrações de banco assumem uma sequência, e
  aplicá-las fora de ordem pode deixar o banco num estado que o código não
  reconhece.
</Warning>

## Se algo der errado

Volte para a imagem anterior e restaure o backup do banco. Restaurar só a
aplicação, sem o banco, não funciona quando a versão nova já migrou o schema.
