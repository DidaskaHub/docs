Cada pessoa tem um papel na plataforma. O papel define o que ela vê e o que ela
pode fazer.

| | Proprietário | Administrador | Professor | Aluno |
|---|---|---|---|---|
| Ver e estudar cursos | ✓ | ✓ | ✓ | ✓ |
| Criar e editar cursos | ✓ | ✓ | ✓ | |
| Corrigir avaliações | ✓ | ✓ | ✓ (dos próprios cursos) | |
| Ver relatórios de alunos | ✓ | ✓ | ✓ (dos próprios cursos) | |
| Convidar e gerenciar pessoas | ✓ | ✓ | | |
| Configurar a plataforma | ✓ | ✓ | | |
| Gerenciar cobrança | ✓ | | | |

## Como escolher

- **Professor** para quem produz conteúdo e acompanha alunos. É o papel certo
  para a maior parte da sua equipe pedagógica.
- **Administrador** só para quem precisa mexer em configuração e em cadastro de
  pessoas. Administrador demais é o caminho mais comum para mudança acidental.
- **Proprietário** é único e responde pela conta.

## Acesso a cursos

O papel diz o que a pessoa pode fazer; a **matrícula** e a **turma** dizem em
quais cursos. Proprietário e Administrador veem e mexem em todos os cursos da
plataforma.

O professor trabalha nos cursos que leciona — os que têm o nome dele no passo
**Professores** do curso — e nos que ele criou. Fora deles, ele não vê nem
mexe:

- **Simulados**: a lista, a correção, as métricas e os resultados mostram só as
  provas desses cursos. Ao criar um simulado, ele escolhe entre os cursos dele.
- **Relatórios e análises**: os números e os alunos são os dos cursos dele.
- **Insights da Didaska IA**: a opção geral aparece para ele como **Todos os
  seus cursos**. Para o Proprietário e o Administrador, ela se chama
  **Plataforma inteira**.
- **Didaska Stream**: ele conduz a aula ao vivo dos cursos que leciona. Na aula
  de outro curso, entra como participante.
- **Busca**: os resultados trazem os rascunhos dos cursos dele e as pessoas
  matriculadas neles.
- **Recados do curso**: ele escreve, edita e apaga recados só nos cursos dele.

Para o professor acompanhar um curso novo, inclua o nome dele no passo
**Professores** do curso.

## Pessoas e convites

A lista completa de **Usuários** e os **Convites** são de quem administra a
plataforma. O professor ainda escolhe colegas e alunos onde o trabalho dele
pede — por exemplo, ao indicar quem leciona um curso. Veja
[Convidar pessoas](/produto/pessoas/convidar-membros).

## O que fica com a Didaska

A troca do endereço da plataforma e a exclusão da plataforma não ficam em
**Configurações**: quem cuida delas é o suporte da Didaska. A marca — nome,
logo e cores — continua em **Configurações**. Veja [O endereço da sua plataforma](/saas/endereco-da-plataforma) e
[Exclusão da plataforma](/saas/exclusao-da-plataforma).

<Note>
  Mudar o papel de alguém vale imediatamente, inclusive nas sessões que já estão
  abertas.
</Note>
