---
title: "Emissão e validação de certificados"
description: "Como os certificados são emitidos automaticamente, como o aluno faz o download, e como qualquer pessoa valida a autenticidade pelo código único."
---

Cada modelo de certificado tem uma opção de **emissão automática**. Com ela ativada, quando o aluno atinge as condições de conclusão do curso o certificado é gerado, o aluno é notificado e pode baixar o PDF — sem você precisar emitir manualmente.

<Note>
  A funcionalidade de certificados pode estar ativa ou não na sua escola. Se não estiver disponível, verifique em **Configurações → Funcionalidades**.
</Note>

## Como a emissão automática funciona

Com a emissão automática ativada no modelo, o certificado é emitido assim que o aluno cumpre os requisitos de conclusão do curso:

1. **Todas as aulas obrigatórias assistidas.**
2. **Aprovação no quiz final** — se o curso tiver um quiz com nota mínima configurada.

Quando as duas condições são atendidas (ou só a primeira, se não houver quiz), a plataforma:

- Gera o PDF com o modelo configurado para o curso.
- Preenche todos os campos dinâmicos com os dados do aluno.
- Cria o **código de validação único**.
- Envia uma **notificação** para o aluno na plataforma.
- Envia um **e-mail** com o certificado em anexo (quando o e-mail está configurado na escola).

Tudo isso acontece de forma instantânea, sem intervenção manual.

## O que o aluno precisa fazer

Quando o aluno recebe a notificação de que o certificado está disponível:

<Steps>
  <Step title="Acesse os certificados">
    No menu da plataforma, clique em **Meu perfil → Meus certificados** (ou clique direto na notificação recebida).
  </Step>
  <Step title="Localize o certificado">
    Todos os certificados emitidos aparecem em uma lista, com o nome do curso e a data de conclusão.
  </Step>
  <Step title="Baixe o PDF">
    Clique em **Baixar certificado**. O PDF é gerado e o download começa imediatamente.
  </Step>
</Steps>

O certificado pode ser baixado quantas vezes o aluno quiser. Não há prazo de expiração para o download.

## Código de validação

Cada certificado recebe um código único no momento da emissão. Esse código:

- Aparece no PDF (você define a posição no modelo usando o campo dinâmico **Código de validação**).
- É único de cada certificado emitido.
- Pode ser usado por qualquer pessoa para verificar a autenticidade.

## Validação pública

Qualquer pessoa pode validar um certificado — sem precisar ter conta na Didaska.

<Steps>
  <Step title="Acesse a página de validação">
    Abra a página pública de validação da escola — o endereço fica indicado no próprio certificado.
  </Step>
  <Step title="Informe o código">
    Digite o código de validação que aparece no certificado e clique em **Verificar**.
  </Step>
  <Step title="Veja os dados">
    Se o certificado for válido, a página exibe:
    - Nome completo do aluno.
    - Nome do curso concluído.
    - Nome da escola emissora.
    - Data de conclusão.
  </Step>
</Steps>

<Check>
  A validação confirma que o certificado foi emitido pela escola na Didaska e que os dados são autênticos. Certificados falsificados ou alterados não passam pela validação.
</Check>

### O que acontece se o código não for encontrado?

Se o código informado não existir no sistema, a página de validação exibe uma mensagem de alerta. Isso pode acontecer se:

- O código foi digitado incorretamente.
- O certificado foi emitido fora da plataforma Didaska.
- O certificado foi falsificado.

## Emitir uma nova versão

Em alguns casos você pode precisar gerar o certificado de novo:

- **Atualização do modelo:** os certificados já emitidos continuam com o layout antigo. Para que o aluno receba a versão atualizada, é preciso emitir novamente.
- **Correção de dados:** se o nome do aluno estava incorreto no cadastro, corrija o cadastro primeiro e então emita um novo certificado.

<Warning>
  Cada nova emissão gera um certificado com um **novo código de validação** — o código anterior não é reaproveitado. Se o aluno já salvou ou imprimiu o certificado anterior, oriente-o a baixar a versão nova. Avalie emitir de novo conforme a necessidade — uma mudança pequena de layout nem sempre justifica gerar para todos.
</Warning>

## Perguntas frequentes

<AccordionGroup>
  <Accordion title="O certificado tem prazo de validade?">
    Não. Os certificados emitidos pela Didaska não expiram. O aluno pode baixar e validar o documento a qualquer momento, mesmo anos depois.
  </Accordion>
  <Accordion title="E se o aluno perder o PDF?">
    O aluno pode acessar **Meus certificados** a qualquer momento e baixar o PDF novamente. O arquivo fica armazenado na plataforma indefinidamente.
  </Accordion>
  <Accordion title="Posso emitir um certificado fora do fluxo automático?">
    Em circunstâncias especiais — como um aluno que concluiu o curso fora da plataforma — pode ser necessário gerar um certificado manualmente. Confirme com a administração da sua escola se essa opção está disponível no seu plano.
  </Accordion>
  <Accordion title="O certificado é emitido em outros idiomas?">
    Os campos dinâmicos (nome, curso, data) são preenchidos como estão cadastrados. Os textos fixos do certificado (como "Certificamos que") precisam ser escritos manualmente no modelo, no idioma desejado.
  </Accordion>
</AccordionGroup>
